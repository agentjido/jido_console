# Roadmap Epics

Each file in this folder describes one roadmap milestone. Each milestone contains a small set of epics and one release gate.

An epic groups related backlog items. It is not a release by itself. A numbered milestone is complete only when all its epics are complete and the milestone exit gate passes through the production artifact.

Implementation tasks, owners, dependencies, and status belong in Beadwork. The stable capability definitions stay in the [backlog](../backlog/README.md).
