# G0-E09: Define the First-User Support Claim

## Goal

Define who Milestone 1 serves and what first successful use means.

## Scope

- Define the first user.
- Define the user's main job with Jido Console.
- Define one observable activation event and its measure.
- Define the first support claim for product, platform, channel, provider, and security boundaries.
- List explicit non-claims and known limits.
- Align the record with Milestone 1 and the platform-by-channel matrix.

## Out of Scope

- Marketing copy
- Pricing or service-level terms
- New product scope
- Support claims for a later milestone

## Dependencies

This epic has no Gate 0 dependency.

## Pull Request Boundary

Deliver this epic in exactly one pull request. The pull request adds one approved product decision record and its roadmap links.

## Acceptance Checks

- The record gives one clear answer for the first user, main job, activation event, and measure.
- The support claim names each included boundary.
- The non-claims prevent an implied unsupported feature or platform claim.
- The record agrees with the Milestone 1 outcome and release matrix.
- The activation measure can use release evidence without user telemetry.

## Proof Artifacts

- Approved first-user decision record
- Activation definition
- Initial support and non-claim matrix
- Links to Milestone 1 proof requirements

## Milestone Traceability

This epic covers the first user, main job, activation measure, and initial support claim in Gate 0.
